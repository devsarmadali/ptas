# Definition of Done

- Backlog ID and acceptance criteria are referenced.
- Code and documentation agree.
- Domain rules are not duplicated in UI or adapters.
- Authorization and audit effects are covered.
- Database/API changes are documented and backward-compatible where required.
- Tests include successful, invalid, unauthorized and retry/idempotency cases.
- Accessibility is tested for changed priority journeys.
- No RED capability is activated.
- Required checks pass and results are reported.
- Assumptions and unresolved items are recorded.
