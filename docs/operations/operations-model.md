# Operations Model

## Support tiers

- L1: departmental help desk, account/service questions and known workarounds
- L2: application operations, configuration, reconciliation and cloud-service diagnostics
- L3: engineering, database, security and vendor escalation

## Daily controls

- Application and integration health
- Failed jobs and dead-letter queues
- Payment callback and settlement reconciliation
- Backup freshness and storage capacity
- Security alerts and privileged changes
- Pending approval queues and aging

## Required runbooks

- Application outage
- Database outage or saturation
- Failed/duplicate payment callback
- Settlement mismatch
- Document generation failure
- Offline sync backlog
- Lost field device
- Incorrect tax schedule or form version
- Unauthorized access or suspected data exposure
- Backup restore and disaster recovery
- Production release rollback

Numerical SLA, RPO, RTO, retention and escalation contacts remain approval gates.
