# Content Guidelines

- Use departmental terms only after validation; show abbreviations with their full form initially.
- State what happened, what the user must do next and by when.
- Do not imply automatic legal approval.
- Error messages identify the field/problem and a recovery action without exposing sensitive data.
- Confirmation pages show reference, amount, status, next step and printable/exportable evidence.
- English is the initial authored language. The layout and component API must support Urdu and right-to-left text; translation requires an approved owner and glossary.
